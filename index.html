What is a Blocktrail?

A sequence of P2TR outputs where each output key commits to application state. Spending an output advances the trail. Bitcoin enforces linearity. No extra tokens. No sidechains. Just keys and hashes.

Nostr-native

Full secp256k1 keys internally. Your Nostr identity works directly.

Minimal

One P2TR output per state update. Key-path spends only.

SPV-compatible

Verify with merkle proofs. No full node required.

Composable

A primitive, not a protocol. Build anything on top.

The Math

# commitment
t = SHA256(state) mod n
d = d_base + t
P = d·G

# on-chain
output = x(P)
